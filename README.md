# Byte Wizard

Byte Wizard is a Python-based command-line IT troubleshooting tool that helps users troubleshoot common computer problems and perform system, network, and security checks.

## Features

- Computer troubleshooting
- System information
- System diagnostics
- Network information
- Network diagnostics
- Firewall security checks
- Quick system and network scan
- Running process monitor
- Top 10 CPU-consuming processes
- PASS / WARNING / FAIL results
- Diagnostic text reports
- macOS, Windows, and Linux support

## Requirements

- Python 3.x
- psutil
- pyfiglet

## Installation

Install the required packages using:

`pip install -r requirements.txt`

Then run:

`python byte_wizard.py`

A standalone macOS executable is also available in the releases folder.
